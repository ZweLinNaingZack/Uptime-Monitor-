# Uptime Monitor: frontend

Next.js (App Router) + TypeScript + Tailwind CSS dashboard for the Uptime Monitor.

See the [project README](../README.md) for how to run it, the project structure, and a
guide to reading the code.

```bash
npm install
npm run dev     # http://localhost:3000
```

Configuration: copy `.env.example` to `.env.local` to point at a different backend URL.
